# 互动零食袋 🎒

一个有趣的互动网页应用，可以打开不同颜色的零食袋并取出零食！

## 功能特点

- ✨ **三个不同颜色的零食袋**：红色、蓝色、绿色
- 🎯 **互动体验**：点击零食袋可以打开它
- 🔒 **单袋限制**：同一时间只能打开一个零食袋
- 🍬 **取出零食**：打开后再次点击可以取出零食袋里的物品
- 🎨 **精美动画**：流畅的打开/关闭动画和物品弹出效果
- ⌨️ **键盘支持**：支持快捷键操作

## 使用方法

### 鼠标操作

1. **打开零食袋**：点击任意零食袋即可打开
2. **取出零食**：打开后再次点击袋子，会取出一个零食
3. **切换零食袋**：点击其他袋子会自动关闭当前袋子并打开新的

### 键盘快捷键

- `1` - 打开/操作薯片袋（红色）
- `2` - 打开/操作糖果袋（蓝色）
- `3` - 打开/操作薯条袋（绿色）
- `Esc` - 关闭所有零食袋

## 零食内容

每个零食袋都有不同的零食：

- **🥔 薯片袋（红色）**
  - 包含5包美味的薯片

- **🍬 糖果袋（蓝色）** 🍬🍭🍫🍩🍪
  - 软糖、棒棒糖、巧克力、甜甜圈、饼干

- **🍟 薯条袋（绿色）**
  - 包含5份香脆的薯条

## 运行方式

### 本地运行

只需在浏览器中打开 `index.html` 文件即可：

```bash
# 使用默认浏览器打开
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

或者使用本地服务器：

```bash
# 使用 Python
python -m http.server 8000

# 使用 Node.js (需要安装 http-server)
npx http-server

# 然后在浏览器中访问 http://localhost:8000
```
